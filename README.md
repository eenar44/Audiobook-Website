# Audiobook-Website
A front-end demo website for a fictional online audiobook store, built as a first-year university project. Includes a working registration form, a promotional advert carousel, and a contact form with client-side validation.

## Live demo
Click [here](https://eenar89.github.io/Audiobook-Website/) to access GitHub pages link.

## Features
- Responsive navbar and footer loaded via external HTML files
- Rotating promotional advert carousel (book of the day, seasonal sales, events)
- Contact form with working email delivery via [EmailJS](https://www.emailjs.com/);  sends a notification to the site owner and an automatic confirmation reply to the visitor
- Mobile navigation SlickNav

## Tech Stack
- HTML
- CSS
- JavaScript
- jQuery
- EmailJS (contact form email delivery)

## Known Limitations
This was an early project, and there are a few things I'd do differently now:
- The CSS (~1200 lines) is functional and reasonably organised although with some repetition. Would need some refining.
- Some article/book cover images used in the "news" and advert sections were sourced from the web rather than created originally. **IMPORTANT NOTE: If you own the rights to any image used here and would like it removed, please reach out and I'll take it down promptly.**
- The sale/event promotional images are AI-generated for the purpose of this _demo_ website. I do not condone the use of AI art used in professional projects.

## Setup
1. Clone or download this repo
2. Open `index.html` in a browser — no build step required
3. To enable the contact form, you'll need your own [EmailJS](https://www.emailjs.com/)
